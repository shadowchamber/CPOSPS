CPOSPS privacy policy

Last updated: 2026-03-26

CPOSPS (Chrome POS Peripheral Simulator) is a browser extension that lets you control simulated POS peripherals by calling a Hardware Station HTTP API that you configure.

Data we store

  • API base URL (for example https://localhost:450/HardwareStation) in chrome.storage.sync.
  • Optional UI preferences such as theme in chrome.storage.sync.

These values stay in your browser profile. They are not sent to CPOSPS authors.

Network

The extension only contacts the Hardware Station (or other host) that you set as the API base. Default host permissions cover localhost and 127.0.0.1. Other hosts require your approval via optional host permission when you save Options.

What we do not collect

  • No analytics, advertising, or third-party trackers in the extension itself.
  • No account sign-in to CPOSPS.
  • No sale of personal data.

Contact

For privacy questions about this extension, open an issue on the CPOSPS repository.
